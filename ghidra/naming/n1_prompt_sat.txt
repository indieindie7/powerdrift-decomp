Sega Saturn game Power Drift (Sega Ages, Sega 1998, Japan GS-9181; port of the 1988 Sega Y-Board arcade racer; GCC SH-2). One program file 00000 loaded at 0x06004000 (code 0x06004000-0x0603a400, data after). Research only. Game: kart-like rollercoaster racing on 5 courses (A-E) of 5 stages each, 12 cars, bonus stages, ARCADE MODE / ARCADE VERSION, GRANDPRIX MODE, EXTRA / NEW COURSE (CRS_N.DAT), options (gear manual/automatic, LEVEL EASY..VERY HARD, control pad / racing controller / multi controller, sound test, BGM select, stereo/monaural), high scores / records, name entry, staff roll, backup RAM. Data files read from CD: CRS_A..E.DAT + CRS_N.DAT (courses), ADV_*.DAT (single course for demo), CAR.DAT, LIN.DAT, MEN.DAT, SEL.DAT, TTL.DAT, END.DAT, LOGO.DAT, SOUND0-6.DAT, CD audio tracks (SOUND_CDDA). File layer debug strings: FILE_INIT(TRAY_OPEN), FILE_LOAD, FILE_STAT, TEX_OVER, SYSTEM ERROR, SOFT_RESET.
Course data (known from the arcade): each course sub-block = 12-word header, then 2048 track points (x,y,z BE16 words, 6 bytes each) forming a closed loop, trackside object runs (16-byte entries), a 32-entry object set (12-byte records), an AI driving script (12-byte entries per car), a word table, colour data. The arcade game logic: race_LoadCourse, the player car (steering, gears low/high, speed, drift, jump/air time on raised track, crash/spin), 11 AI cars following driving scripts, position/rank, lap counting, timer and time extend, scoring/points, road renderer drawing the track as segments from the point list, sprites for trackside objects/cars/scenery, attract demo.
